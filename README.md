# Stairway to Injury (Godot 4 MVP Scaffold)

Starter implementation of the MVP architecture for a vertical split-screen 2.5D ragdoll damage simulator.

## Structure

- `project.godot` — project config (9:16 viewport)
- `scenes/` — menu, intro, simulation, result scenes
- `scripts/` — gameplay systems (game manager, ragdoll, damage, replay, face mapping, camera)
- `TECHNICAL_SPEC.md` — implementation mapping and next milestones

## Notes

This is a foundation scaffold, not a full content-complete game yet. The systems are intentionally modular so each MVP criterion can be wired incrementally.
